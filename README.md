# Coffee Menu - freeCodeCamp Project

A clean and responsive coffee shop menu website built as part of the freeCodeCamp "Responsive Web Design" certification. This project focuses on foundational HTML5 structure and advanced CSS3 styling techniques.

## 🚀 Technologies Used
* **HTML5:** Semantic structure.
* **CSS3:** Custom properties (variables), responsive design, fonts, layouts, and hover effects.

## 📝 Features
* Full responsiveness for mobile, tablet, and desktop screens.
* Styled using a warm, coffee-themed color palette.
* Organized menu items with pricing and alignment.
* Clean semantic code practice.
